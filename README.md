## การเปิดโปรเจกต์

1. แตกไฟล์ ZIP
2. เปิด Android Studio
3. เลือก Open แล้วเลือกโฟลเดอร์ `BMICalculator`
4. รอ Gradle Sync
5. Run บนอุปกรณ์หรือ Emulator ที่ใช้ Android 7.0 หรือใหม่กว่า

## ฟังก์ชันหลัก

- รับน้ำหนักหน่วยกิโลกรัมและส่วนสูงหน่วยเซนติเมตร
- รับจำนวนเต็มหรือทศนิยมไม่เกิน 2 ตำแหน่ง
- แสดง BMI เป็นทศนิยม 2 ตำแหน่ง
- แสดงระดับ Underweight, Normal, Overweight หรือ Obese พร้อมสี
- มี Layout แยกสำหรับแนวตั้งและแนวนอน
- เปลี่ยนภาษาอังกฤษและภาษาไทยตามภาษาเครื่อง
- เมื่อขนาดตัวอักษรของระบบเปลี่ยน แอปให้เลือกใช้ค่าระบบหรือคงขนาดปัจจุบัน

## หลักการคำนวณ

สูตร BMI คือ น้ำหนักกิโลกรัมหารด้วยส่วนสูงหน่วยเมตรยกกำลังสอง ผลจะปัดเป็นหนึ่งตำแหน่งก่อนแสดงสองตำแหน่ง เพื่อให้ตรงกับตัวอย่างใน Checklist:

- 65 kg, 168 cm แสดง 23.00
- 80 kg, 180 cm แสดง 24.70

ช่วง BMI สำหรับผู้ใหญ่:

- ต่ำกว่า 18.5: Underweight
- 18.5 ถึงต่ำกว่า 25: Normal
- 25 ถึงต่ำกว่า 30: Overweight
- ตั้งแต่ 30 ขึ้นไป: Obese
